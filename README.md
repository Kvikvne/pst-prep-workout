# pst-prep-workout

A single-page workout tracker. The week alternates KB + calisthenics days
with run days (Mon/Wed/Fri KB workouts, Tue/Thu/Sat runs, Sunday rest), all on one unified page —

Training load scales automatically based on how many weeks remain until your ship date: set your
date once (saved in the browser so you don't re-enter it) and the app derives the current phase —
BASE, BUILD, PEAK, or TAPER — adjusting tempo pace/distance, zone 2 and long run mileage, and KB
Grinder Circuit rounds accordingly.
